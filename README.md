# Elsewhere Travel Planner

A lightweight, standalone travel-planning webpage. Visitors enter trip details and receive an itinerary outline, a rough budget estimate, and practical planning tips.

## Use it

1. Open `index.html` in a modern web browser.
2. Enter a destination and any other trip details you know.
3. Select **Build my itinerary** to see the results below the form.
4. Update your answers and submit again to refine the draft.

No installation or server is required. The form and itinerary generation run in the browser; submitted details are not sent to a server.

## What it includes

- Destination, dates or duration, departure point, traveler group, budget, pace, accommodation, interests, and special-needs fields.
- A day-by-day outline organized by morning, afternoon, and evening.
- A rough trip budget breakdown and a short logistics checklist.
- A responsive layout for desktop and mobile screens.

## Estimate limitations

The itinerary is generated from simple browser-side templates and the answers provided. Budget figures are generic placeholders, not live destination prices. The page does not check flight or hotel availability, entry requirements, current opening hours, or local conditions. Verify those details before booking.
